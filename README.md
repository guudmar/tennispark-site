# Сайт «Тенниспарк»

Новый сайт теннисного клуба Tennispark (Ростов-на-Дону, Левобережная ул., 69 · +7 928 296-07-30 · ежедневно 7:00–22:00). Замена текущему сайту на Tilda: https://tennispark.ru

Живой сайт: https://guudmar.github.io/tennispark-site/ — публикуется GitHub Pages из ветки `main` репозитория https://github.com/guudmar/tennispark-site (корень). Обновление: закоммитить и `git push` из этой папки, через минуту-две изменения на сайте.

Приватное превью (артефакт Claude): https://claude.ai/artifact/Hg941oiF4h6svy82s3y24o — Яндекс Карта там не грузится, это ограничение просмотрщика, вместо неё видна нарисованная схема. Обновляется повторной публикацией `index.html` из этой папки.

Статический сайт без сборки: открыть `index.html` через любой веб-сервер (не как `file://`, иначе браузер не загрузит модуль 3D-сцены).

```bash
python3 -m http.server 8765 --directory tennispark-site
```

## Блоки страницы

1. **Первый экран.** 3D-комплекс из пяти грунтовых кортов на закате. При загрузке прорисовываются линии и поднимаются сетки. Скролл ведёт камеру с высоты за заднюю линию, дальше розыгрыш из четырёх ударов: на каждом отскоке всплывает подпись (12+ кортов, с 5 лет, 14 тренеров, 7:00–22:00), а табло считает 15, 30, 40, ГЕЙМ. Последний мяч летит прямо в камеру и заливает экран цветом войлока, из которого начинается следующий блок. Без WebGL показывается фото кортов; при «уменьшить движение» в системе анимация отключается.
2. Манифест на «войлоке» с гербом.
3. Четыре направления: школа, аренда, индивидуальные, группы (на десктопе за курсором едет фото).
4. Корты: хард или грунт, схема корта с размерами.
5. Ролик о клубе, раскрывающийся по скроллу.
6. Детская школа: этапы 5–6, 6–8, 9–10, 11+, до 18 лет с мячом, катящимся по линии; группы и родители.
7. Тренеры: 14 человек с фильтром «Детям / Взрослым / Тренажёрный зал».
8. Инфраструктура: 8 пунктов, фото меняется по активному пункту.
9. Тренажёрный зал.
10. Турниры: причины участвовать и таблица летнего сезона 2026.
11. Запись: форма собирает заявку и открывает WhatsApp клуба (`wa.me/79282960730`) с готовым текстом.
12. Контакты с Яндекс Картой (под картой нарисована запасная схема) и подвал.

## Что править

- Тексты и тренеры — прямо в `index.html` (карточки `.coach`, у каждой `data-tags`: `kids`, `adults`, `gym`, `tennis`).
- Список тренеров в форме записи — объект `COACH` в скрипте в конце `index.html`.
- Номер WhatsApp — константа `WA` там же.
- Турниры — таблица в блоке `#tournaments`. Когда появится расписание нового сезона, замените строки и статус «Сыгран».
- Траектория мяча, камера, цвета сцены — `assets/hero.js` (`buildRally`, `broadcast`, константы в начале файла).
